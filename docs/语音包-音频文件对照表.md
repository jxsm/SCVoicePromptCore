# 语音包 - 音频文件对照表

> 录完音频后，按本表「文件名」列命名（含扩展名），放入模组音频目录即可。
> 音频格式：引擎支持 .wav / .ogg / .mp3 / .flac（Engine/Engine.Media/SoundData.cs:27）。
> **用 WAV 时的硬性要求**（引擎 Wav.cs:229 校验，不满足直接报"Unsupported WAV format"）：
> - 必须是 **PCM 未压缩**（导出时选"PCM 16-bit"；不能是 32-bit float、ADPCM、MP3 封装的 wav）
> - 位深必须是 **16-bit**
> - 采样率 **8000–48000 Hz**（推荐 44100 或 22050；96000/192000 不行）
> - 声道 **单声道或立体声**（语音推荐单声道，体积减半）
> 全表共 **150 个音频文件**，按优先级分批制作：**P0=核心必做**（高频生存提示）、**P1=建议做**（中频）、**P2=可选**（低频/一次性/调试）。

## 命名规则（为什么这样起名）

- 文件名 = `语言段名_键号`，与语言包 JSON 的键一一对应。
- 核心模组（VoicePrompt.core）运行时把当前提示文本反查语言包得到键号，再播放对应文件，**切换游戏语言也不会失配**；文件不存在则静默跳过。
- 带部位参数的寒冷提示（{0}=部位）在键号后追加部位后缀：`_Head / _Torso / _Legs / _Feet`。
- 死亡原因类文本不弹小字（走死亡记录），若不想配音可跳过，模组会自动忽略。

## 工程结构（核心 + 语音包，2026-10 拆分）

语音系统拆成「核心 + 音频包」两个模组，**文件名规范不变**，只是音频多了一层包目录：

- **VoicePromptCore**（PackageName：`VoicePrompt.core`）：全部逻辑——提示拦截、文本反查、冷却去重、设置（开关/音量/冷却/**选择语音包**）。不含音频。
- **NeuroVoicePack**（PackageName：`voice.prompt.pack.neuro`）：纯音频资源包，无代码，声明依赖核心（`"Dependencies": { "VoicePrompt.core": "^1.0" }`）。

音频文件放在自己包 id 的子目录下（包 id = PackageName 去掉 `voice.prompt.pack.` 前缀）：

```
NeuroVoicePack/Assets/Audio/Voice/neuro/ComponentVitalStats_12.ogg
                                  ^^^^ 自己的包 id
```

**自制新语音包只需三步**：

1. modinfo.json：`PackageName` 填 `voice.prompt.pack.<你的id>`（id 只用字母数字和 `_-.`），声明依赖 `VoicePrompt.core: ^1.0`，`NonPersistentMod: true`、`GameplayImpactLevel: "Cosmetic"`；不需要写任何代码和 Settings。
2. 音频按本表文件名放到 `Assets/Audio/Voice/<你的id>/` 下（只放想配的，缺的自动跳过）。
3. 打包成 .scmod 放入 Mods 目录。核心会自动发现它（可多包共存），在核心的模组设置里选择用哪个包（全局生效）；未选择时取 LoadOrder 最大的包。

（游戏会把所有模组的 Assets 平铺合并进同一个资源管理器，所以每个包必须用**自己的子目录**，否则多包会互相覆盖。）

详细制作步骤见同目录《[语音包制作指南](语音包制作指南.md)》。

## 录音建议

1. **动态参数台词**（`ComponentMiner_1`、`ComponentMiner_12`、`ComponentClothing_1` 含工具名/数字）：只录固定部分，模组播放时文本原样显示、语音播后半句即可；追求完整可后期拼接。
2. **部位 24 条**建议同一录音批次完成（仅一词之差，音色一致）。
3. 每条语音控制在 **1.5～3 秒**；同类提示（如"该吃点东西了"）游戏会周期性重复弹，模组侧应做**冷却去重**（如 60 秒内同键不重播），避免刷屏。
4. 文件名大小写保持与本表一致；扩展名可统一 .wav 或 .ogg（模组按基础名查找，两种都能识别）。WAV 用 **PCM 16-bit / 44100Hz / 单声道** 导出，全表约 30MB；若在意体积可降为 22050Hz（约 15MB）或后期转 OGG。
