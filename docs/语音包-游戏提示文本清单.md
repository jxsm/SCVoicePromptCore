# 生存战争（SurvivalcraftApi）游玩提示文本清单

> 用途：语音包模组（Voice Pack）配音底稿。
> 整理日期：2026-10-14　|　游戏版本源码：SurvivalcraftApi 工程

## 一、机制速览（语音包如何挂接）

- 所有提示文本存放于语言包 JSON：`Survivalcraft/Content/Assets/Lang/zh-CN.json`（共 8 种语言，结构一致）。
- 代码通过 `LanguageControl.Get(类名, 键号)` 取文本，类名对应 JSON 顶层键（如 `ComponentVitalStats`）。
- **拦截点（模组钩子）**，位于 `Survivalcraft/ModsManager/ModLoader.cs`：
  - `DisplaySmallMessage(ComponentGui, ref text, ref color, ref blinking, ref playNotificationSound, out skip)`（ModLoader.cs:433）——绝大多数游玩提示都走这里，钩子收到的是**最终文本字符串**（随游戏语言变化）。
  - `DisplayLargeMessage` 同样有钩子（ComponentGui.cs:168）——开场剧情、烟花大字。
  - 生命值类还有 `OnVitalStatsEat / OnVitalStatsUpdateFood / UpdateStamina / UpdateSleep / UpdateTemperature / UpdateWetness`（ModLoader.cs:2138 起）——可直接按数值阈值触发语音，不依赖文本匹配，**换语言也不会失效**。
- ⚠️ **不走 DisplaySmallMessage 的文本**（下表"渠道"列已标注）：
  - `好困啊……`/`好热啊……` 走 `ComponentScreenOverlays.FloatingMessage`（画面浮现字）。
  - 死亡原因文本走 `Injure()` → 死亡界面/死亡记录，不弹小字。
  - 睡眠界面、状态面板标签为静态 UI 文本。

**渠道说明**：小字=DisplaySmallMessage（可被钩子拦截）；大字=DisplayLargeMessage；浮字=ScreenOverlays；死亡=死亡原因记录；界面=静态 UI。
