# 语音包制作指南（Survivalcraft 插件版）

> 本指南教你为自己的角色/偶像做一套游戏语音包。**不需要写任何代码**，只要准备音频文件、一个 modinfo.json，打包成 `.scmod` 装进游戏即可。
>
> 前置要求：安装了 [Voice Prompt Core 语音提示核心](../README.md)（`VoicePrompt.core`）。

---

## 一、原理：核心和语音包是怎么配合的

语音系统分成两部分：

- **核心（VoicePrompt.core）**：负责全部逻辑——监听游戏提示（"你饿了""好冷啊""弩已装填"……）、把提示文本反查语言包得到**逻辑键名**（如 `ComponentVitalStats_12`）、冷却去重、播放选中语音包里的对应文件。
- **语音包（你做的）**：纯音频资源。核心按「包名前缀」自动发现所有已安装的语音包，玩家在核心设置里选一个用（全局生效，可随时换）。

所以你只需要：**按约定的文件名放音频**。游戏是中文、英文还是俄文都没关系——反查得到的是键名而不是文本，翻译永远不会失配。没配的键自动静默跳过，一套语音包配 10 条也能用，配齐 150 条也行。

游戏会把所有模组的资源**平铺合并**进同一个资源管理器，因此每个语音包的音频必须放在**自己包 id 命名的子目录**里，多包才不会互相覆盖。

## 二、准备

1. 一批音频（或能录音/剪辑的软件）。
2. 知道自己想配哪些提示 → 打开 [语音包-音频文件对照表](语音包-音频文件对照表.md)，里面有全部 **150 个键位**的文件名、台词和触发场景，按优先级分了 P0（核心必做）/P1（建议）/P2（可选）。
3. 一个能打 zip 的工具（Windows 自带 PowerShell 即可），或者 .NET 10 SDK（想用工程模板打包的话）。

## 三、开始制作

### 1. 起一个包 id

包 id 只用**字母、数字、`_`、`-`、`.`**，例如 `myaqua`、 `vtuber_kafka`。你的模组包名 = 前缀 + 包 id：

```
voice.prompt.pack.myaqua
```

包 id 同时也是你的音频子目录名，两者必须一致。

### 2. 建目录

```
MyAquaVoicePack/                    ← 工程根目录（名字随意）
├── modinfo.json
├── ExtraPrompts.json               ←（可选）第三方模组提示映射，见第七节
└── Assets/
    └── Audio/
        └── Voice/
            └── myaqua/             ← 你的包 id
                ├── ComponentVitalStats_12.ogg
                ├── ComponentVitalStats_27_Head.ogg
                ├── ComponentGui_13/         ←（可选）随机变体文件夹，见下文
                │   ├── a.ogg
                │   ├── b.ogg
                │   └── c.ogg
                └── ...
```

### 3. 写 modinfo.json

直接抄这个模板，改 `Name`、`Author`、`PackageName`、`Description`：

```json
{
  "$schema": "https://gitee.com/SC-SPM/SurvivalcraftApi/raw/SCAPI1.9/Survivalcraft/Content/modinfo-scheme.json",
  "Name": "MyAqua 语音包（MyAqua Voice Pack）",
  "Version": "1.0.0",
  "ApiVersion": "1.9.3",
  "Description": "MyAqua 的游戏提示语音。需配合 Voice Prompt Core 语音提示核心使用。",
  "ScVersion": "2.4.0.0",
  "LoadOrder": 10001,
  "NonPersistentMod": true,
  "GameplayImpactLevel": "Cosmetic",
  "Author": "你的名字",
  "PackageName": "voice.prompt.pack.myaqua",
  "Dependencies": {
    "VoicePrompt.core": "^1.0"
  }
}
```

字段说明：

| 字段 | 值 | 说明 |
|---|---|---|
| `PackageName` | `voice.prompt.pack.<你的id>` | **核心靠这个前缀发现语音包**，必须以 `voice.prompt.pack.` 开头 |
| `Dependencies` | `VoicePrompt.core: ^1.0` | 声明依赖核心。核心没装时你的包会被游戏自动禁用并提示原因，而不是装了没反应 |
| `NonPersistentMod` | `true` | 纯资源模组不往存档写数据，卸载不留痕，必填 true |
| `GameplayImpactLevel` | `Cosmetic` | 纯外观（语音）模组，不影响玩法平衡 |
| `LoadOrder` | 10001（可自定） | 玩家没在设置里选包时，核心自动取 **LoadOrder 数值最大**的包作为默认 |
| `Version` | `1.0.0` | 建议语义化版本，发新版改这里 |
| `ApiVersion` | `1.9.3` | 核心支持的最低 API 版本，照抄即可 |

**不要**写 `Settings`、不要放任何 `.dll`——语音包就是纯资源。

### 4. 放入音频（命名规则）

文件名 = `语言段名_键号[_部位].ogg`，与对照表一一对应：

| 规则 | 例子 |
|---|---|
| 普通：`语言段名_键号` | `ComponentVitalStats_12.ogg`（该吃点东西了） |
| 寒冷部位提示：再追加部位后缀 `_Head / _Torso / _Legs / _Feet` | `ComponentVitalStats_27_Head.ogg`（头部寒冷提示） |
| 特例：磁铁超限提示不走语言包，固定名 | `MagnetBlock_TooMany.ogg` |

要点：

- **只放你想配的**。缺的键核心直接跳过，不报错。
- 键号来自游戏语言包，**与游戏语言无关**——文件名永远是英文段名+数字。
- 文件名区分大小写按常规写法抄对照表即可；扩展名小写 `.ogg`。
- 部位后缀仅寒冷提示（`ComponentVitalStats` 27~32）使用，四种部位都要才有完整效果。

#### 随机变体：一条提示配多条语音（核心 ≥ 1.1.0）

同一个键除了放单个文件，还可以放一个**同名文件夹**，里面放任意多条音频，核心每次触发时**随机挑一条**播放——适合"同一句提示有 N 种语气"的趣味玩法：

```
Assets/Audio/Voice/myaqua/
├── ComponentVitalStats_12.ogg        ← 单文件：每次都播这条
└── ComponentGui_13/                  ← 文件夹：每次从里面随机挑一条
    ├── happy.ogg
    ├── annoyed.ogg
    └── sleepy.ogg
```

规则：

| 项 | 说明 |
|---|---|
| 文件夹名 | 与单文件命名完全相同，只是没有扩展名（如 `ComponentGui_13/`、`ComponentVitalStats_27_Head/`） |
| 内部文件名 | **随意**（`1.ogg`、`happy.ogg` 都行），建议只用英文、数字、下划线 |
| 条数 | 任意；只有 1 条等效单文件。多条时核心会**避免连续两次抽到同一条** |
| 文件夹与单文件并存 | **文件夹优先**，旁边的同名单文件会被忽略 |
| 嵌套子文件夹 | 会一并算进随机池，但没有意义，建议平铺 |
| 冷却 | 按提示键整体计冷却（文件夹算"一句"），不会因变体多而刷得更勤 |
| 兼容性 | 旧版核心（< 1.1.0）不认文件夹，会静默跳过——用了文件夹的包请把依赖写成 `^1.1` |
| ExtraPrompts | `File` 字段同样支持：声明的文件名若是文件夹，一样随机挑一条 |


### 5. 打包成 .scmod

`.scmod` 本质就是普通 zip，**根目录**必须有 `modinfo.json` 和 `Assets/`（不要多套一层文件夹）。

方法 A：PowerShell（Windows 自带，无需安装）：

```powershell
cd MyAquaVoicePack
Compress-Archive -Path modinfo.json, Assets -DestinationPath MyAquaVoicePack.scmod -Force
```

方法 B：.NET 工程（推荐要长期维护的作者，改完音频一键重打包）。最小工程只要两个文件：

`MyAquaVoicePack.csproj`：

```xml
<Project Sdk="Microsoft.NET.Sdk">
    <PropertyGroup>
        <OutputType>Library</OutputType>
        <TargetFramework>net10.0</TargetFramework>
        <AssemblyName>MyAquaVoicePack</AssemblyName>
        <LangVersion>preview</LangVersion>
        <EnableDefaultCompileItems>false</EnableDefaultCompileItems>
        <GenerateAssemblyInfo>false</GenerateAssemblyInfo>
        <GenerateDependencyFile>false</GenerateDependencyFile>
    </PropertyGroup>
    <ItemGroup>
        <None Update="modinfo.json">
            <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
        </None>
        <None Update="ExtraPrompts.json">
            <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
        </None>
        <None Update="Assets\**\*">
            <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
        </None>
        <Compile Include="ResourcePack.cs"/>
    </ItemGroup>
    <Target Name="PostBuild" AfterTargets="PostBuildEvent">
        <PropertyGroup>
            <PathOfScmod>$(TargetDir)..\$(AssemblyName).scmod</PathOfScmod>
        </PropertyGroup>
        <ZipDirectory SourceDirectory="$(TargetDir)" DestinationFile="$(PathOfScmod)" Overwrite="true"/>
    </Target>
</Project>
```

`ResourcePack.cs`（占位文件，内容一行注释即可，csc 需要至少一个源文件）：

```csharp
// 纯音频资源包：不含任何代码。
```

然后 `dotnet build`，产物在 `bin\Debug\MyAquaVoicePack.scmod`。资源包不含代码，无需任何 NuGet 依赖，离线也能构建。

### 6. 安装与验证

1. 把 `.scmod` 放进游戏的 `Mods` 目录（Windows 版一般在 `Survivalcraft.Windows\bin\Debug\Mods`，或游戏安装目录下的 `Mods`）。
2. 启动游戏，进入任意世界，触发一个你配过的提示（比如饿了）。
3. 看日志（`Bugs` 目录下的日志文件或控制台）确认这几行：

```
VoicePromptCore: found voice pack [voice.prompt.pack.myaqua] "MyAqua 语音包", N audio files.
VoicePromptCore: active voice pack [voice.prompt.pack.myaqua] (N audio files).
```

4. 装了多个包时，在**模组管理 → Voice Prompt Core 设置 → 语音包**里选择用哪个（全局生效，所有存档共用）。

## 四、音频格式要求

引擎支持 `.ogg / .wav / .mp3 / .flac`，**推荐 OGG**（体积小质量好，本仓库示例即 OGG）。

用 WAV 时的硬性要求（引擎校验，不满足直接报 "Unsupported WAV format"）：

- **PCM 未压缩**（导出时选 "PCM 16-bit"；不能是 32-bit float、ADPCM、MP3 封装的 wav）
- 位深 **16-bit**
- 采样率 **8000–48000 Hz**（推荐 44100 或 22050）
- 声道**单声道或立体声**（语音推荐单声道，体积减半）

时长建议每条 1~3 秒。核心默认开启「**打断当前语音**」（可在核心设置里关闭）：新语音触发时立即切断上一条；同时 1 秒全局间隔与每句冷却仍然生效，不会连珠炮。

## 五、常见问题

| 现象 | 原因与解决 |
|---|---|
| 装了没声音，日志没有 `found voice pack` | `PackageName` 前缀写错（必须 `voice.prompt.pack.` 开头），或音频目录名与包 id 不一致 |
| 日志有 `Failed to find dependency` / 模组被禁用 | 没装核心 `VoicePrompt.core`，或核心版本不在 `^1.0` 范围 |
| 发现了包但某条不响 | 文件名拼错（对照表核对）；或该提示走了未覆盖的通道（大字横幅/死亡原因本来就不配音） |
| 随机变体文件夹不生效 | 核心版本低于 1.1.0（旧核心不认文件夹，会静默跳过），确认装的 `VoicePrompt.core ≥ 1.1.0` |
| 报 "Unsupported WAV format" | 见上面 WAV 硬性要求，重新导出 |
| 两个包互相覆盖/串音 | 音频没放进自己包 id 的子目录。每个包必须 `Assets/Audio/Voice/<你的id>/` |
| 切了游戏语言后不响 | 不应该发生（匹配走键名不走文本）；若出现请提 issue，并附日志里 `indexed N exact + M pattern` 那行 |
| 声音太小/太大 | 核心设置里的「语音音量」是倍率，也可在音频软件里统一归一化到 -3dB 左右 |

## 六、进阶说明

- **优先级**：玩家未手动选择时，核心取 `LoadOrder` 数值最大的包。想让你的包成为"默认被选中"，把 LoadOrder 设大一点（比如 20000）；官方示例包是 10001。
- **核心的多语言**：核心界面文案在 `VoicePromptCore/Assets/Lang/`（en-US 兜底 + zh-CN），欢迎参照 en-US.json 补充其他语言：游戏支持 en-US / zh-CN / ru-RU / es-419 / pt-BR / ro-RO / tr-TR / vi-VN。语音包本身不需要任何多语言处理。
- **完整键位清单**：[语音包-音频文件对照表](语音包-音频文件对照表.md)（150 键，含台词与触发场景）；各提示通道的说明见 [语音包-游戏提示文本清单](语音包-游戏提示文本清单.md)。

## 七、为第三方模组提示配音（ExtraPrompts.json）

核心内置的键位注册表只覆盖原版提示。想给**其他模组**弹出的提示配音，在你的语音包根目录（和 modinfo.json 同级）放一个 `ExtraPrompts.json`，声明该模组提示的「语言段名 + 键号」到本包音频文件名的映射即可，核心发现你的包时会一并入索引。

**适用条件**（绝大多数插件版模组都满足）：

1. 该提示走小字 / 画面浮字 / 大字横幅通道（即通过 `ComponentGui.DisplaySmallMessage`、`DisplayLargeMessage` 或画面浮字显示）；
2. 提示文案来自该模组的语言包键（模组带 `Assets/Lang/*.json`、代码里用 `LanguageControl.Get` 取文案）——这样匹配才不会因游戏语言而失配。

**格式示例**：

```json
{
  "Prompts": [
    { "Section": "ExampleModLoader", "Key": "1" },
    { "Section": "ExampleModLoader", "Key": "2", "File": "ExampleMod_Special" },
    { "Section": "SomeSubsystem", "Key": "5" }
  ]
}
```

**规则**：

| 项 | 说明 |
|---|---|
| `Section` / `Key` | 必填。该模组语言包 JSON 的顶层键（段名）和数字键号 |
| `File` | 可选。音频文件名（不含扩展名）；缺省为 `段名_键号`；也可以填随机变体文件夹的名字（核心 ≥ 1.1.0，见第三节「放入音频」） |
| 音频位置 | 必须放在**你自己包的音频目录**下（`Assets/Audio/Voice/<你的id>/<File>.ogg`），文件名不能含 `/` 或 `\` |
| 带参数的模板 | 文案含 `{0}`（工具名、数字等）时核心自动按参数模板正则匹配，无需特殊处理 |
| 生效范围 | 只有**当前选中的语音包**的扩展映射会生效——每个包声明自己的，互不冲突；如果声明的键在当前语言包里不存在，核心记一条警告并跳过 |

打包提示：用方法 A（PowerShell）时记得把该文件加进 `-Path` 列表（`-Path modinfo.json, ExtraPrompts.json, Assets`）；用方法 B 的工程模板已默认包含它的复制条目（文件不存在时不影响构建）。

**怎么找段名和键号**：打开该模组的 `.scmod`（就是 zip），看 `Assets/Lang/en-US.json` 或 `zh-CN.json`——JSON 的顶层键就是段名（通常是模组主类的 `fName`），里面的数字键就是键号；对照游戏里实际弹出的文案即可确认是哪一条。

**验证**：启动游戏看日志，发现语音包的行会显示扩展条数：

```
VoicePromptCore: found voice pack [voice.prompt.pack.myaqua] "MyAqua 语音包", 42 audio files, 3 extra prompts.
```

进入世界后还有一行 `indexed ... extra 3` 表示扩展映射已入索引。条目没生效时优先检查：JSON 格式是否合法、Section/Key 是否和该模组语言包一致、音频文件是否真的在包目录里（缺文件会静默跳过，但映射数会正常显示——注意区分）。
